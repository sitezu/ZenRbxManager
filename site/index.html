Made to stay focused

Everything in its place.

The tools you need to organize accounts and start a Roblox session, with an interface that stays out of your way.

▦
One account workspace

Search, filter, select, reorder and label your accounts. Keep a short note with each one.

⊕
Two ways to add

Sign in through a supported browser or import your own Roblox security cookie. Roblox verifies the account identity.

↗
Launch where you want

Open Roblox Home or enter a Place ID and optional server Job ID. Launch one selected account or several.

◈
Local encrypted storage

On first setup, saved accounts are encrypted on your machine. Exported settings exclude login cookies.

◉
Presence at a glance

Online and in-game status appears when Roblox returns it. Unknown stays unknown; Away can be marked manually.

✦
Make it yours

Switch accents, choose a login browser, set launch delays and configure Windows Startup.

A simple flow

Set up once.
Stay in control.

ZenRbxManager runs on Windows using an installed browser for its interface, so it doesn't bundle a heavyweight browser engine. Your account list stays on your computer.

  1. 01
    Get the Windows app or run from source

    Follow the repository guide. Edge or Chrome is needed for the app window.

  2. 02
    Add an account you own

    Use the browser login flow or import a Roblox security cookie you control.

  3. 03
    Choose an account and launch

    Open Roblox Home or enter a Place ID. Roblox and internet access are required.

Built in the open, for your desktop.

Good to know

Is ZenRbxManager an official Roblox app?

No. This is an independent open-source community project, not affiliated with or endorsed by Roblox.

Do I need to install a browser?

Yes. The desktop interface opens using an installed Edge or Chrome browser. Website login may require a matching WebDriver. The app does not bundle a browser.

Where are my accounts stored?

Locally in the app's AccountManagerData folder. A new setup enables hardware-based encryption. Back up your data before moving computers; a vault from another machine may need its original environment.

Can I download a ready-made Windows executable?

Not until a Windows build is published and tested. For now, see the run-from-source instructions. The repository workflow enforces a 100 MB limit for the executable.
