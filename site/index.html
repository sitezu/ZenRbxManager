The useful stuff, up front

Less digging. More playing.

Pick an account, find your place, and go. The little details — names, notes, and status — are there when you need them.

▦
Know which account is which

Give accounts a label, add a quick note, and drag them into an order that makes sense to you. Search when the list gets long.

⊕
Add them your way

Sign in through a browser, or import a security cookie from an account you own. The app checks the account with Roblox before saving it.

↗
Go straight to the game

Open Roblox Home, enter a Place ID, or join a specific server with a Job ID. Select more than one account when you need to.

◈
Your accounts stay on your PC

The app keeps saved accounts locally and encrypts a new vault on first setup. Exporting preferences never exports login cookies.

◉
A useful status, not a guess

See online or in-game status when Roblox makes it available. When it doesn’t, we say “Unknown” instead of pretending.

✦
Set it up your way

Choose a color, pick the browser for sign-in, and adjust the time between launches. Small things, but they add up.

Three steps, no big manual

From account list
to game in a few clicks.

ZenRbxManager is a Windows app. It uses a browser already on your computer for the interface, so there's no extra browser bundled with it.

  1. 01
    Grab the preview (or run the source)

    The preview release includes a portable EXE. You’ll need Edge or Chrome for the app window.

  2. 02
    Bring in an account you own

    Use the browser sign-in or import your own Roblox security cookie. Keep that cookie private.

  3. 03
    Pick where you’re going

    Choose an account and launch Roblox Home or a specific Place ID. Roblox and an internet connection are still required.

Want to know what’s under the hood? It’s all there.

The account backend comes from the open-source Evanovar RAM project. Because account tools handle sensitive sessions, you should be able to read the code before trusting it. The download is labeled preview until someone has verified a Roblox login and launch on Windows.

Good to know

Is this made by Roblox?

No. ZenRbxManager is an independent open-source project. It isn’t made, approved, or supported by Roblox.

Do I need anything installed first?

You’ll need Windows 10 or 11 and Edge or Chrome to open the interface. You’ll also need Roblox to launch a game. Browser-based sign-in may download a matching WebDriver the first time you use it.

Where does it keep my accounts?

In an AccountManagerData folder on your computer. A new setup turns on hardware-based encryption. Please keep a backup — a vault tied to one machine may not open on another.

Where can I get the Windows app?

Download the preview release on GitHub. It passes automated tests and a 100 MB size check, but has not been tested with a real Roblox login or game launch on Windows yet. If you prefer, run it from source.
